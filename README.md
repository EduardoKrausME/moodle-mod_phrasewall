# Phrase wall

Phrase wall is a Moodle activity for collecting one short sentence from each student and displaying the submissions as a visual wall. It is designed for quick reflections, summaries, opinions, takeaways, exit tickets and other activities where the teacher wants concise participation instead of long-form answers.

## How it works

The teacher adds a Phrase wall activity and defines the maximum sentence length and whether student names should be visible to the class. Each student submits one sentence, which is immediately presented on the wall according to the activity settings.

When anonymous mode is enabled, students do not see who wrote each sentence, while teachers can still identify authors in the management report. Teachers can also decide whether students may edit their own submission after posting.

## Main features

- one sentence per student;
- configurable sentence limit from 60 to 280 characters;
- identified or anonymous wall for participants;
- optional editing of the student's own sentence;
- teacher report with submission authorship;
- teacher ability to delete submissions;
- optional activity completion after submission;
- backup and restore of activity data and student submissions;
- Moodle Privacy API integration;
- responsive interface for desktop and mobile use.

## Student experience

Students open the activity, write their sentence within the configured limit and submit it. If editing is allowed, they can return later and update their own sentence. The wall gives the class a quick overview of the group's responses without turning the activity into a discussion forum.

## Teacher experience

Teachers can review the wall as students see it and access the administrative report when they need authorship information or moderation controls. Anonymous mode only changes what participants see; it does not remove the teacher's ability to identify submissions.
