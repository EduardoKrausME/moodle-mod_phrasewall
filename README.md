# mod_phrasewall - Mural de uma frase

Atividade Moodle para coletar uma frase curta de cada estudante e exibi-la em um mural visual.

## Como funciona

Cada estudante envia uma frase dentro do limite definido pelo professor. O mural pode mostrar o nome do autor ou operar
em modo anônimo para a turma, enquanto o professor continua tendo acesso à autoria no relatório administrativo.

## Recursos

- uma frase por estudante;
- limite configurável de 60 a 280 caracteres;
- mural identificado ou anônimo;
- edição opcional da própria frase;
- exclusão de respostas pelo professor;
- conclusão opcional após o envio;
- backup e restauração das respostas;
- integração com a Privacy API do Moodle;
- interface responsiva.
