# mod_phrasewall - Mural de uma frase

Atividade Moodle extremamente simples para coletar uma frase curta de cada estudante e exibi-la em um mural visual.

## Recursos

- Uma frase por estudante.
- Limite configurável de 60 a 280 caracteres.
- Mural com nome do estudante ou anônimo.
- Professor mantém acesso à autoria no relatório administrativo, inclusive quando o mural é anônimo.
- Edição opcional da própria frase.
- Professor pode excluir respostas.
- Conclusão da atividade opcional após o envio da frase.
- Backup e restauração com respostas dos usuários.
- Implementação da Privacy API do Moodle.
- Interface responsiva usando Mustache e CSS, sem renderer próprio.

## Compatibilidade

Moodle 4.5 ou superior.

## Instalação

Copie a pasta `phrasewall` para `mod/phrasewall` e conclua a atualização administrativa do Moodle.
